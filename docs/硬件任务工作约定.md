# 硬件任务工作约定（2026-11-23 定，长期有效）

> 缘起：智能饮水机课设 PCB 打了三次样（v1 排母方向错、v2 蜂鸣器供电电压错+两个接口针序错+缺 5V 输出端子），
> 全部是"凭推断/记忆代替实物核对"造成的。以下约定用于防止复发。

## 一、根本原则

**不靠记忆和推断，只靠证据。**

- 涉及硬件针序、极性、电压，一律以**实物照片、丝印特写、万用表读数**为准；
- AI 不给"我记得应该是……"的结论；
- 用户必须亲手核对并复述确认，AI 只提供判据与方法。

## 二、标准流程（每次硬件任务）

```
① AI 列出"待核对清单"（只列问题，不下结论）
② 用户提供证据：照片 / 丝印特写 / 万用表读数
③ AI 逐字读证据后给判断
④ 用户复述确认："针1=？针2=？针3=？"
⑤ 落表：接口针序表（模块丝印 -> 板上焊盘 -> 源码引脚，三列对齐）
⑥ 打板前完成"三表核对"并签字式确认
```

## 三、每次必查的五件事

| # | 必查项 | 证据形式 | 反例（本次踩的坑） |
|---|---|---|---|
| 1 | **接口针序** | 模块实物**丝印特写照片** | TDS 写成 +5V/GND/A，实际是 GND/+5V/A |
| 2 | **供电电压与逻辑阈值** | 模块资料或实测 | 蜂鸣器用 5V 供电，高电平阈值 2.5V，3.3V MCU 输出被判低 -> 常响 |
| 3 | **1 脚方向** | 芯片**插入后**拍照，按插入姿态判断 | 蓝pill USB 朝右时两排上下互换，导致 v1 报废 |
| 4 | **大电流模块的电源端子** | 板上必须有对应座子 | MOS/水泵无 5V 输出座，只能飞线 |
| 5 | **中间验证** | 打板前按"未来板子的接法"用面包板接一遍 | 直接打板，问题到焊完才暴露 |

## 四、AI 的行为约束

1. 硬件相关结论**必须标注证据来源**（哪张照片、哪次测量）；
2. 无法确认时**明确说"不确定，需要你拍照/实测"**，不给猜测性结论；
3. 每次改板**只改一处、立刻验证一处**，不打包批量改；
4. 打板前必须主动输出"投板前检查清单"，逐项等用户确认；
5. 用户是执行者：**方法由 AI 给，动作由用户做，数据由用户报**——避免"AI 代劳导致用户没学会"。

## 五、投板前检查清单（模板，每次复制使用）

```
□ 两排/多排排母 1 脚方向（方形焊盘位置）与实物插入姿态一致
□ 每个接口的针序与模块丝印逐字一致（三列对照表已填）
□ 每个模块的供电电压正确（5V / 3V3 分开确认，特别是阈值敏感器件）
□ 大电流负载（电机/水泵/继电器）有独立电源端子
□ 去耦电容位置正确（贴芯片电源脚）
□ 丝印：组号 + 项目名 + 引脚定义文字与焊盘顺序一致
□ DRC 0 错误；5V 与 GND 蜂鸣档不短路
□ 关键接口在面包板上复现验证过
```
