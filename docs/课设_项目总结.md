## 二、系统架构

### 硬件

```
5 V/2 A 适配器 → DC-005 → 5 V 母线（C1 220 µF + C2 100 nF）
                              ├→ TDS 模块（U6, XH3P）
                              ├→ CN1（5 V 输出→MOSFET→水泵）
                              └→ 核心板 → 板载 AMS1117 → 3.3 V 母线
                                                          ├→ OLED（U1, 1×4）
                                                          ├→ DS18B20（U7, XH3P）
                                                          ├→ 触摸（H1, 1×3 排针）
                                                          ├→ 蜂鸣器（U5, 1×3）
                                                          └→ R1 4.7 kΩ（DQ 上拉）
```

### 引脚分配

| 引脚 | 功能 | 连接 | 配置要点 |
|---|---|---|---|
| PA0 | ADC1_IN0 | TDS 模块 A 端 | 12 位、右对齐、采样 71.5 周期、ADC 时钟 /6 = 12 MHz |
| PA1 | GPIO 开漏 | DS18B20 DQ | 外接 4.7 kΩ 上拉，DWT 微秒时序 |
| PA2 | GPIO 输入 | TTP223 OUT | 内部上拉，低电平有效，5 ms 轮询 + 15 ms 去抖 |
| PA3 | GPIO 输出 | 蜂鸣器 I/O | 低电平触发，模块 VCC 必须 3.3 V |
| PA4 | GPIO 输出 | MOSFET SIG | 高电平导通，长按出水 3 s 自动停 |
| PB6 | GPIO（软件 I²C 的 SDA） | OLED SDA | 见"问题六"：与硬件 I²C1 相反，故用软件 I²C |
| PB7 | GPIO（软件 I²C 的 SCL） | OLED SCL | 约 150 kHz |

### 软件结构

```
上电 → 时钟/GPIO/ADC/I²C/DWT 初始化 → 软件 I²C 初始化 → 探测 0x78/0x7A
     → SSD1306 初始化（含 0x8D 0x14 电荷泵）→ 主循环（5 ms 节拍）

主循环：
  ① 触摸状态机（15 ms 去抖）：短按切页 / 长按开泵并计时
  ② 每 500 ms 采一次 TDS → mV → ppm（厂家经验公式）
  ③ DS18B20 两段式（启动 / 760 ms 后读取），非阻塞
  ④ 水泵计时满 3 s 自动关闭（PA4 拉低，PC13 灯灭）
  ⑤ ppm ≥ 500 → PA3 拉低 → 蜂鸣器响
  ⑥ 脏标记驱动重绘（仅数据变化时刷屏）
  ⑦ I²C 连续 3 次失败 → 总线恢复（9 时钟 + STOP）→ 重初始化
```

## 三、实测数据

| 测试项 | 条件 | 结果 |
|---|---|---|
| TDS 输出 | 空气 | ≈ 0.02 V（0 ppm） |
| TDS 输出 | 自来水 | ≈ 0.73 V（≈ 330 ppm） |
| TDS 输出 | 加盐水 | > 1.5 V（> 2000 ppm） |
| 水温 | 室温 | 22.0 ℃ |
| 水温响应 | 手捏探头 | 升至 28 ℃ |
| 报警 | ppm ≥ 500 | 蜂鸣器响；浓度回落自动停止 |
| 水泵 | 长按 1 s | 运行 3 s 自动停止 |
| 页面切换 | 短按 | 两页正常切换 |
| 稳定性 | 连续运行 30 min | 无死机、无复位 |

## 四、踩过的坑（按发生顺序）

| # | 问题 | 根因 | 解决 |
|---|---|---|---|
| 1 | 第一版 PCB 排母方向画反 | 核心板 USB 朝右插入时两排上下互换，设计时按错误的姿态放置 | 调换 U2/U3 的 Y 坐标，1 脚保持右端；重投板 |
| 2 | 蜂鸣器上电常响 | 模块 VCC 接 5 V 时高电平阈值为 2.5 V，MCU 的 3.3 V 经负载拉低到 0.6 V 被判为低电平 | 模块 VCC 改接 3.3 V（阈值降至 1.6 V）；第三版把该网络与丝印同步修正 |
| 3 | 水泵启动导致屏幕熄灭、按键失灵 | 电脑 USB 限流 500 mA，水泵瞬态电流把 5 V 拉低，MCU 欠压复位 | 改用 5 V/2 A 适配器；水泵经 MOSFET 由同一 5 V 母线供电并共地 |
| 4 | 长按关泵要按多次 | 水泵纹波耦合到触摸输出，电平抖动使"长按"被误判为多次短按 | 触摸输入加 15 ms 去抖；交互改为"长按出水 3 秒自动停" |
| 5 | I²C 偶发锁死，屏停在最后一帧 | 负载开关的电压尖峰使从机拽住 SDA | 增加总线恢复：DeInit → SCL/SDA 转开漏 GPIO → 9 个时钟 → 手动 STOP → 重新初始化 |
| 6 | 屏插到底板始终黑屏 | 底板把 OLED 的 SCL/SDA 接到 PB7/PB6，与硬件 I²C1（PB6=SCL、PB7=SDA）相反 | 改用软件模拟 I²C，引脚按底板实际走线（PB7=SCL、PB6=SDA） |
| 7 | DS18B20 读数恒为 85.0 ℃ | 数据线缺 4.7 kΩ 上拉 | 增加 R1 上拉；同时确认 DWT 微秒延时正确 |

## 五、方法论收获

1. **先测量、再定位、后修改**：每次故障先量电压/通断，用数据缩小范围，而不是"再烧一次试试"。
2. **一次只改一处并立即验证**：联调阶段坚持"插一个模块测一次"，问题才能定位到具体环节。
3. **结论必须有证据**：外设针序以实物丝印照片为准，不能凭记忆和直觉；第三版因此避免了更多返工。
4. **万用表的局限**：未焊接的排母孔与方针（1.0 mm vs 0.64 mm）接触不良，通断测量会误判为断路；直流通断也测不出"接触电阻几欧但 I²C 信号失效"的问题。
5. **干扰环境下交互要容错**：能自动完成的操作（如定量出水）不应依赖用户再按一次。

## 六、可改进方向

1. TDS 增加两点标定与温度补偿，提高绝对精度。
2. 蜂鸣器供电在原理图阶段即统一为 3.3 V，并核对所有模块的电平判别阈值。
3. 原理图完成后逐条核对"网络名—引脚—功能"，尤其是复用功能引脚。
4. 增加数据记录（SD 卡/无线）与上位机，替代当前只能靠屏显示的方式。
5. 结构上增加水位检测，避免水泵空转。
