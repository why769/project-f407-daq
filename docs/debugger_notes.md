# 调试器课三条观察（2026-10-31 W1 D2）

## 观察1：F10单步看寄存器跳变
断点打在MODER行，F10两步：
- RCC_AHB1ENR: 0x00100000 → 0x00100020（bit5亮=GPIOF时钟开了）
- GPIOF_MODER: 0x00000000 → 0x00040000（PF9配成输出）
结论：寄存器跳变亲眼可见，不用猜。

## 观察2：ODR bit9翻转
全速跑+反复暂停，GPIOF_ODR的bit9在0和1之间交替（值含/不含0x0200）。
结论：BSRR翻转ODR，ODR驱动引脚电平，LED跟着闪。

## 观察3：注释RCC行→灯死
注释掉 RCC_AHB1ENR |= 1<<5 → 烧录 → 灯灭。取消注释 → 灯活。
结论：不开时钟=外设睡着=写寄存器白写。这是新手"代码对了灯不亮"的头号原因。
