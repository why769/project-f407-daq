# 原理速记卡（背诵用 · 每张 3 句）

> 用法：每天开工前 5 分钟，随机抽一张，合上资料复述三句；说不全的做标记，第二天再抽。

## 卡 1 · I2C 时序
1. **是什么**：两根开漏线（SCL 时钟 / SDA 数据）+ 上拉电阻，多设备共享，靠 7 位地址区分。
2. **为什么这样**：开漏只能拉低，所以多个设备同时拉低不会短路；起始/停止定义为"SCL 高时 SDA 跳变"，是为了让命令与数据帧永不混淆。
3. **怎么用**：`HAL_I2C_Master_Transmit(&hi2c, 0x78, buf, n, timeout)` 一次 = START + 地址 + ACK + n 字节 + 各自 ACK + STOP；`IsDeviceReady` 只发地址等 ACK，用于探测。

## 卡 2 · ADC
1. **是什么**：把 0~Vref 的电压切成 2^12=4096 格，输出 0~4095 的码值；LSB = Vref/4096 ≈ 0.806mV。
2. **为什么这样**：内部逐次逼近（二分查找），每个比较周期需要稳定时间，所以 ADC 时钟上限 14MHz；采样电容充满才能测准，源阻抗大就要加长采样时间（本项目 71.5 周期）。
3. **怎么用**：`Start → PollForConversion → GetValue`，再 `mV = code*3300/4096`；Vref 实际偏差会按比例带进所有读数（要标定）。

## 卡 3 · DS18B20 单总线
1. **是什么**：一根开漏线双向通信，把时钟编码进"低电平持续多久"里；温度 16 位有符号数，分辨率 0.0625℃。
2. **为什么这样**：必须开漏+4.7k 上拉，否则主从同时驱动会短路；从机靠"下降沿后 15~60µs 定时采样"判 0/1，所以短低=1、长低=0；读时主机先拉低再释放，是为了把总线让给从机。
3. **怎么用**：复位(≥480µs)→0xCC 跳过 ROM→0x44 启动转换→等 750ms→复位→0xCC→0xBE 读 9 字节；**读到 85℃ = 通信失败**（多数是缺上拉）。

## 卡 4 · 电源与电平
1. **是什么**：逻辑阈值是"判高判低的电压门槛"，它**随模块自身供电电压变化**（5V 供电门槛约 2.5V，3.3V 供电约 1.6V）。
2. **为什么这样**：模块内部输入级直接接自己的电源轨；所以 5V 模块配 3.3V MCU 会出现"MCU 输出高、模块判成低"（本项目蜂鸣器即此坑）。
3. **怎么用**：优先让模块与 MCU 同压供电；不行就加电平转换；去耦电容贴芯片脚，大电流负载（水泵）与模拟信号（TDS）单点共地。
