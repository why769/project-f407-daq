# 课设调试与设计问题记录（第25组 · 智能饮水机水质安全系统）

> 用途：报告 4.5 节「问题分析与解决」的素材；也是面试"你遇到过什么坑"的答案库。
> 记录格式：现象 → 定位过程 → 根因 → 解决 → 教训。

## 1. 底板排母方向画反（设计级错误，导致第一次打样报废 5 片）

- **现象**：PCB 到手，蓝pill 插上去后，板子上排右端（USB 侧）丝印是 `B12`，下排右端是 `GND`——与设计假设相反。
- **定位过程**：① 先用万用表测通断，发现"都不响"（未焊接时孔与针接触不良，此测试无效）；② 改为**直接读两端丝印**：上排左 `3.3V` / 右 `B12`，下排左 `VBT` / 右 `GND`；③ 对照蓝pill 引脚表判断出**两排上下互换**。
- **根因**：蓝pill 的引脚编号以 USB 端为起点；当 USB 朝右插入时，其"上排（GND,GND,3V3…）"物理上落在板子**下边**，而设计把 U2（上排网络）放在了上边，U3 放在下边，**上下颠倒**。
- **解决**：EDA 中把 U2 与 U3 的 Y 坐标互换（U3→y=80 在上，U2→y=64.76 在下），两排 1 脚（方形焊盘）保持在**右端**；重新走线后 DRC 清零，第二次投板。
- **教训**：
  1. **连接器的 1 脚方向必须与实物对准，且要按"插入姿态"验证**，不能只看原理图；
  2. 未焊接时**万用表通断测不出**（1.0mm 孔 vs 0.64mm 针，间隙 0.36mm），此时应**读丝印**而不是测通断；
  3. 投板前把"核心板插入示意"画出来，比对着想象更可靠。

## 2. 蜂鸣器"接上就长响"（阈值与供电的陷阱）

- **现象**：蜂鸣器 I/O 接 PA3 后持续鸣叫；拔掉 I/O 线即停。
- **定位**：① 用杜邦线**手动将 I/O 碰 GND** → 响，确定模块为**低电平触发**（丝印正确）；② 测 PA3 电压仅 **0.6V**（应为 3.3V）→ 输出被模块拉低；③ 判断为**供电电压决定输入阈值**。
- **根因**：模块 VCC 接 5V 时，其高电平判据约 ≥2.5V；3.3V MCU 经线阻后仅 0.6V，被模块判为低电平 → 持续触发。
- **解决**：**蜂鸣器 VCC 改接 3.3V**，阈值降至约 1.6V，PA3 3.3V 稳定判为高，恢复正常。报警逻辑：`ppm ≥ 500 → PA3 拉低 → 响`。
- **教训**：**传感器/执行器模块的逻辑阈值随其供电电压变化**，5V 模块配 3.3V MCU 常见"输出高却被判低"，处理方式：降供到 3.3V 或加电平转换。

## 3. CubeMX 选 `SYS → Debug = No Debug` 导致 SWD 被禁（芯片"变砖"）

- **现象**：练习工程生成后烧录正常，但之后再连接报 `Unable to get core ID` / `No STM32 target found`。
- **根因**：`No Debug` 会生成禁用 SWJ 的代码，SWD 引脚被释放为普通 IO，调试口失效。
- **解决**：断电 → **BOOT0 拨到 1**（从系统存储器启动，SWD 复位默认可用）→ 上电 → 烧录正确固件 → 断电 → **BOOT0 拨回 0**。
- **教训**：**新建工程第一件事就是配 `SYS → Serial Wire`**；救砖首选 BOOT0=1 窗口，比"按住复位"可靠。

## 4. 3D 预览"排母平躺"引发误判

- **现象**：3D 视图里 2×20 排母显示为平躺薄片，看不到插孔。
- **定位**：切回 2D 看焊盘类型——圆形焊盘带孔 = 通孔（THT），数量 20、间距 2.54、1 脚方形在右，全部正确。
- **根因**：元件库的 3D 模型为简化模型，方向画错。
- **教训**：**3D 模型不能作为设计正确性判据**；判据是 2D 焊盘类型 + 孔距 + 1 脚标记。

## 5. 铺铜距板边 0.257mm < 0.3mm（DRC 5 条间距错误）

- **原因**：铺铜多边形贴板框绘制。
- **解决**：铺铜轮廓向内缩 0.3–0.5mm 后重建铺铜；不建议通过放宽设计规则来"消错"。

## 6. 通孔焊盘不可穿越（布线阶段）

- **现象**：把 +3V3 换到底层走线后，DRC 仍报"导线到插件焊盘距离 0mm"。
- **根因**：排母、XH 座为**通孔元件，顶层与底层都有铜**，换层不能穿越焊盘。
- **解决**：绕行——走板边通道与元件之间的空带；母座两排焊盘间距仅 1.74mm，0.8mm 线无法穿过。

## 7. 面包板接线与测量方法

- 面包板同组 5 孔互通（本板竖放时为横排互通），中间凹槽绝缘；电源轨可能中间断开，需蜂鸣档确认。
- **未焊接的排母孔与方针接触不良**，通断测量会误判为"断路"，此时以丝印/原理图为准。
