## 一、电平与信号（最基础，必须一次搞透）

| 术语 | 一句话 | 用你的板子举例 | 面试怎么说 |
|---|---|---|---|
| ★ 高电平 / 低电平 | 电压的两种"状态"，不是"有没有电" | 3.3V=高，0V=低 | 数字电路只看两个区间，不看中间值 |
| ★ 有效电平 | 这个电平代表"动作发生" | 蜂鸣器低电平触发：给 0V 才响 | 低有效是硬件省电/抗干扰习惯，不是错误 |
| ★ 正逻辑 / 负逻辑 | 高=1 叫正逻辑；低=1 叫负逻辑 | KEY0 按下为低=负逻辑按键 | 看原理图定，别凭直觉 |
| ★ 上升沿 / 下降沿 | 电平跳变的**那一瞬间**，不是持续状态 | PA2 从 0→3.3V 的瞬间＝上升沿 | 边沿触发只在跳变时动作，电平触发在持续期间一直动作 |
| ★ 上拉电阻 | 用电阻把引脚"默认拉到高电平" | I2C 的 SDA/SCL 必须上拉 | 给悬空引脚一个确定状态，防止误触发 |
| ★ 下拉电阻 | 用电阻把引脚"默认拉到低电平" | PA2 配下拉＝不碰时 0V | 下拉 + 上升沿 = 按下变高 |
| ★ 浮空（高阻） | 既不拉高也不拉低，电压不确定 | 没配上拉/下拉的输入脚 | 浮空脚会被干扰乱跳，是"玄学故障"根源 |
| ★ 推挽输出 | 内部上下两个开关管，**能主动输出高也能输出低** | PC13 点灯用的就是推挽 | 驱动能力强，但两个推挽不能直接并联（会打架） |
| ★ 开漏输出 | 只有下拉管，**只能拉低，高电平靠外部上拉** | I2C 用开漏 | 可以"线与"：多设备挂同一总线不冲突 |
| 高阻态（三态） | 输出相当于"断开"，不影响总线 | 总线释放时 | 多设备共享总线时靠它让出总线 |
| 驱动能力 | 一个引脚能给出的电流 | 普通 IO 约 8–20mA，PC13 更弱 | 带不动大电流负载，要加三极管/MOS |
| 共地 | 所有设备的 GND 连在一起 | 板子、ST-Link、模块必须共地 | 不共地＝没有共同电压参考，读数全乱 |
| 上拉/下拉的"强/弱" | 电阻越小越"强" | 10kΩ 是弱上拉，1kΩ 强 | 强上拉抗干扰但费电 |

## 二、电源相关

| 术语 | 一句话 | 举例 |
|---|---|---|
| ★ VCC / VDD / GND | 电源正 / 芯片电源正 / 地（0V 参考） | 板子上 3V3、5V、GND 三种丝印 |
| ★ LDO | 低压差线性稳压器，把 5V 稳成 3.3V | 蓝pill 上那颗 AMS1117-3.3 |
| ★ 3V3 是"输出"不是"输入" | 它接在 LDO 的输出端 | 从外面灌 3.3V 进去会顶坏 LDO |
| ☆ 去耦电容 | 贴在芯片电源脚旁的小电容，滤高频、供瞬时电流 | 底板留 100nF（高频）+ 220µF（储能） |
| ☆ 限流电阻 | 串在回路里限制电流 | LED 串 1kΩ |
| ☆ 地环流 | 多个接地点电位不同，形成环路电流 | USB 隔离器就是为它买的 |
| ☆ 单点接地 | 大电流（水泵）和小信号（TDS）只在一个点汇合 | 底板设计要点，也是报告创新点 |
| · 纹波 | 电源上叠加的交流成分 | 影响 ADC 精度 |

## 三、时钟

| 术语 | 一句话 | 举例 |
|---|---|---|
| ★ 晶振（HSE） | 外部高精度时钟源 | 板上 8MHz 晶振 |
| ★ 内部 RC（HSI） | 芯片内置时钟，精度差但便宜 | 8MHz，HSE 挂了当备胎 |
| ★ PLL（锁相环） | 倍频器，把低频变高频 | 8MHz × 9 = 72MHz |
| ★ 分频 / 倍频 | 除 / 乘 | APB1 除 2 得 36MHz |
| ★ 主频（SYSCLK） | CPU 跑多快 | 72MHz |
| ☆ AHB / APB1 / APB2 | 三条总线，速度不同 | APB1 上限 36MHz |
| ★ Flash 等待周期 | 高频时 Flash 跟不上，要插等待 | 72MHz 下 `FLASH_LATENCY_2` |
| ☆ 时钟树 | 从晶振到各外设的分频关系图 | CubeMX 那页就是它 |

## 四、GPIO 与寄存器

| 术语 | 一句话 | 举例 |
|---|---|---|
| ★ 寄存器 | 芯片里的一块"开关面板"，按位控制硬件 | `GPIOA->ODR` |
| ★ 位 / 掩码 | 一个 bit 代表一个开关；掩码是"只动指定位" | `reg |= (1<<2)` |
| ★ 端口 / 引脚 | GPIOA 是端口，PIN_2 是其中第 2 脚 | PA2 = 端口 A 的第 2 脚 |
| ★ 复用（AF） | 一个引脚被借给外设用 | PA9 复用成 USART1_TX |
| ★ 输入模式 4 种 | 浮空 / 上拉 / 下拉 / 模拟 | 模拟输入是给 ADC 的 |
| ★ 输出模式 2 种 | 推挽 / 开漏 | 点灯用推挽 |
| ☆ 寄存器手册 | 查每个位干什么的官方文档 | STM32F4xx 中文参考手册 |

## 五、中断（面试重灾区）

| 术语 | 一句话 | 举例 |
|---|---|---|
| ★ 中断 | 硬件事件打断 CPU 当前工作，先去处理它 | 按键 → 灯翻转 |
| ★ 中断向量表 | 一张"中断号 → 处理函数地址"的表 | 复位后从 0x08000004 取 Reset 地址 |
| ★ ISR（中断服务函数） | 真正被调用的那个函数 | `EXTI2_IRQHandler` |
| ★ 回调（Callback） | HAL 留的口子，用户实现业务 | `HAL_GPIO_EXTI_Callback` |
| ★ 挂起（Pending） | 事件已发生、置了标志，但还没被处理 | `EXTI->PR` 第 2 位 |
| ★ 使能（Enable） | 给这个中断"发通行证" | `HAL_NVIC_EnableIRQ` |
| ★ 抢占优先级 | 能不能打断正在跑的中断 | 数越小越优先 |
| ★ 子优先级 | 同时到的时候谁先 | 抢占相同才比它 |
| ★ 消抖 | 机械抖动会产生多次边沿，要过滤 | 20ms 时间戳法 |
| ★ volatile | 告诉编译器"这变量会被外部改，别优化" | 中断与主循环共享的变量 |
| ★ 中断里不能做什么 | 不能长时间延时、不能阻塞、不能调重活 | `HAL_Delay` 禁止 |
| ☆ 中断上下文 | ISR 运行的环境，栈和任务不同 | RTOS 里必须用 FromISR 版本 API |

## 八、三条理解主线（比背术语重要）

1. **一切外设都是"时钟 → 引脚 → 数据 → 中断"四问**。会问这四句，任何外设都能自己啃下来。
2. **电平是状态，边沿是瞬间**。配中断 = 选边沿；配输入 = 定状态（上/下拉）。
3. **推挽能给高给低，开漏只能拉低**。所以 I2C 必须上拉，点灯用推挽。
