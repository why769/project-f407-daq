- RTOS 面试必答（重原理，不是"会调 API"）：
  - 中断上下文 vs 任务上下文的区别；为什么中断里必须用 FromISR 版本 API
  - 队列和信号量分别解决什么问题；为什么用队列不用全局变量
  - 优先级反转如何产生、Mutex（优先级继承）如何解决
  - 任务划分依据、中断最小化原则
- 投递方向：深圳（消费电子/通信/储能）、东莞、广州、杭州、苏州；岗位关键词：MCU、嵌入式软件、固件、BSP。
